Throughput time = process time + move time + queue time + inspection time. Manufacturing cycle efficiency (MCE) = process time ÷ throughput time. Delivery cycle time = wait time + throughput time. This plant already runs with zero inspection time, so inspection time is 0.0 in every month.

Required:
  1. Compute the following for each of the four months:
    1. Throughput time
    2. Delivery cycle time
    3. Manufacturing cycle efficiency (MCE)
  2. Evaluate the company's performance over the last four months.
  3. Refer to the data for month 4.
    1. Assume that in month 5 the company uses Lean Production to completely eliminate the queue time, and all else remains the same as in month 4. Compute the new throughput time and MCE.
    2. Assume that in month 6 the company eliminates all queue time and inspection time, and all else remains the same as in month 4. Compute the new throughput time and MCE.
