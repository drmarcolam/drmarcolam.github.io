Problem

Pisgah Mercantile Co.

Pisgah Mercantile Co. is a Brevard-based merchandiser that reported the following information based on 1,000 units sold for the month.

Given data

ItemAmount
Sales$285,000
Beginning merchandise inventory$19,000
Purchases$190,000
Ending merchandise inventory$9,500
Fixed selling expense? — solve for this
Fixed administrative expense$11,400
Variable selling expense$14,250
Variable administrative expense? — solve for this
Contribution margin$57,000
Net operating income$17,100

Cost of goods sold equals beginning inventory plus purchases minus ending inventory, and — because Pisgah Mercantile is a merchandiser — the entire cost of goods sold is variable with unit sales. Start there, then use the contribution margin to solve for variable administrative expense, and use net operating income to solve for fixed selling expense.
