Problem

Blue Ridge Precision Industries

Blue Ridge Precision Industries, a Hendersonville, North Carolina, machine shop, is automating one of its plants and developing a flexible manufacturing system. In an effort to revise its performance measurement system, the company gathered the following data for the last four months.

The president read in industry journals that throughput time, manufacturing cycle efficiency (MCE), and delivery cycle time are important measures of performance, but no one is sure how to compute them. You have been asked to assist the company using the data below.

Throughput time = process time + inspection time + move time + queue time. Manufacturing cycle efficiency (MCE) = process time ÷ throughput time. Delivery cycle time = wait time + throughput time.

Required:
  1. Compute the following for each of the four months:
    1. Throughput (manufacturing cycle) time
    2. Manufacturing cycle efficiency (MCE)
    3. Delivery cycle time
  2. Refer to the data for month 4. Assume that in month 5 the inspection time, process time, and so forth, are the same as for month 4, except that the company is able to completely eliminate the queue time using Lean Production. Compute the new throughput time and MCE.
  3. Refer to the data for month 4 again. Assume that in month 6 the inspection time, process time, and so forth, are the same as in month 4, except that the company is able to eliminate both the queue time and the inspection time using Lean Production. Compute the new throughput time and MCE.
