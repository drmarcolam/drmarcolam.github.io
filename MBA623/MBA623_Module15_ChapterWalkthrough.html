Cost behavior

Variable, Fixed, Mixed and Step Costs

Cost behavior describes how total cost responds to changes in activity (such as sales volume).

  • Variable: total changes in direct proportion to activity; zero at zero activity.
  • Fixed: total does not change with activity.
  • Mixed: a fixed element plus a variable element.
  • Step: total jumps to a higher level when activity moves beyond a range.
Example 1 — Cost Behavior

Classify each cost.

Solution

Ingredients vary with output; rent and straight-line depreciation do not. A monthly fee plus a usage charge is mixed. A cost that rises in blocks (supervisors) is a step cost.

Total and average cost

Fixed Cost per Unit Falls as Volume Rises

An order-fulfillment center has monthly fixed costs of $40,000 and variable costs of $0.75 per order.

Total cost = Fixed + Variable cost per unit × Volume. Average cost = Total cost ÷ Volume. Average cost falls as volume grows because fixed costs are spread over more units.

Example 1 — Average Cost at 50,000 Orders

What is the average cost per order at 50,000 orders (two decimals)?

$
Solution

Total = $40,000 + 50,000 × $0.75 = $77,500. Average = $77,500 ÷ 50,000 = $1.55.

Average cost = $1.55

Example 2 — Volume for a $2.35 Average Cost

At what monthly volume is the average cost $2.35 per order?

Need a hint?
Average cost = fixed cost per order + $0.75.
Solution

$2.35 = $40,000/X + $0.75, so $40,000/X = $1.60 and X = 25,000 orders.

Volume = 25,000 orders

Cost estimation

The High-Low Method

A delivery fleet's annual costs were $267,500 at 855,000 miles (highest activity) and $219,500 at 695,000 miles (lowest).

  • Variable cost per unit = (High cost − Low cost) ÷ (High activity − Low activity)
  • Fixed cost = Total cost − Variable cost per unit × Activity
  • Total cost: Y = a + bX
Example 1 — Variable Cost per Mile

Compute the variable cost per mile (two decimals).

$
Solution

($267,500 − $219,500) ÷ (855,000 − 695,000) = $48,000 ÷ 160,000 = $0.30.

Variable cost = $0.30 per mile

Example 2 — Fixed Cost

Compute the annual fixed cost.

$
Solution

$267,500 − $0.30 × 855,000 = $267,500 − $256,500 = $11,000. (Check: $219,500 − $0.30 × 695,000 = $11,000.)

Fixed cost = $11,000

Example 3 — Predicted Cost

Using Y = $11,000 + $0.30X, predict total cost for 800,000 miles.

$
Solution

$11,000 + $0.30 × 800,000 = $11,000 + $240,000 = $251,000.

Predicted cost = $251,000

Example 4 — Estimation Methods

Decide whether each statement is true or false.

Solution

High-low is simple but uses two observations. Regression uses all data and measures fit, but models are tools to aid decisions. Linear estimates assume activity stays in the relevant range.

Comparing cost structures

Fixed vs. Variable: The Crossover Volume

A company can keep its current process (fixed $5,500 plus $0.15 per unit) or adopt a proposed automatic process (fixed $7,000 plus $0.05 per unit).

Example 1 — Equal-Cost Volume

At what volume do the two processes cost the same?

Need a hint?
Set the two total cost equations equal.
Solution

$5,500 + $0.15X = $7,000 + $0.05X, so $0.10X = $1,500 and X = 15,000 units.

Crossover volume = 15,000 units

Example 2 — Which Costs Less?

Choose the lower-cost process at each volume.

Solution

At 10,000 units: current $7,000 vs. proposed $7,500. At 25,000 units: current $9,250 vs. proposed $8,250. The higher-fixed, lower-variable process wins at high volume.

Direct and indirect costs

Traceability and Cost Behavior Together

A cost can be both a behavior type and a traceability type. A cost is direct if it can be traced to a cost object (such as a product) and indirect if it is shared.

Example 1 — Combine Behavior and Traceability

For a cereal company whose cost object is Frosted Flakes, classify each cost.

Solution

Sugar and a dedicated production manager trace directly to Frosted Flakes; utilities and shared machinery serve many products so they are indirect.

Example 2 — Manufacturing Costs

Classify each cost.

Solution

Manufacturing cost = direct materials + direct labor + manufacturing overhead. Selling costs such as commissions are period costs.

Example 3 — Types of Fixed Cost

Classify each fixed cost.

Solution

Committed (capacity) costs are needed to maintain current capacity; discretionary (managed) costs are set by management each period and can be changed.

Wrap-up

Module 15 at a Glance

  • Costs behave as variable, fixed, mixed or step; the linear model holds within the relevant range.
  • Average cost per unit falls as volume rises because fixed costs are spread over more units.
  • High-low: b = ΔCost ÷ ΔActivity, a = Cost − bX; regression uses all data.
  • Classify costs by behavior and traceability; use different costs for different decisions.
