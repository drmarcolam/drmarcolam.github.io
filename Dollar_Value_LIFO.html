On January 1, 2027, Oconaluftee Furniture Company adopted the dollar-value LIFO method. The inventory value for its one inventory pool on this date was $370,000. Inventory data for 2027 through 2029 are as follows:

DateEnding Inventory at Year-End CostsCost Index
Required: Calculate the company's ending inventory for 2027, 2028 and 2029 using dollar-value LIFO.

Each year, first convert the ending inventory to base-year cost by dividing by that year's index. Compare it with the previous year's base-year amount: an increase creates a new layer priced at the current index, and a decrease peels layers off starting with the most recent.
